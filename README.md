🛡️ Phishing Awareness Landing Page

Uma landing page interativa desenvolvida com o objetivo de conscientizar usuários sobre ataques de phishing, engenharia social e golpes digitais.

O projeto apresenta uma experiência imersiva com estética cyberpunk/futurista, animações, efeitos visuais e interações educativas para ensinar como identificar ameaças digitais de forma prática.

🚀 Sobre o Projeto

O phishing é uma das formas mais comuns de ataque cibernético no mundo atualmente.

Esta landing page foi criada para:

Educar usuários sobre phishing
Demonstrar sinais de golpes digitais
Simular ataques reais de engenharia social
Ensinar boas práticas de segurança digital
Criar uma experiência visual moderna e interativa
